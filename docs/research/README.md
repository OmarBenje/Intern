# Recherche et exports

Conserver ici les synthèses Markdown et les manifestes d'entrée revus (sources
ATS, profils d'entreprises). Les fixtures utilisées par les tests restent dans
les dossiers de tests.

Écrire les nouveaux exports d'audit, diagnostics et résultats d'exécution dans
`docs/research/generated/` (ignoré par Git), ou dans un dossier temporaire.
Créer le dossier avant de lancer une commande avec `--report`.

Le 1er octobre 2026, les exports JSON/JSONL non versionnés accumulés pendant les
lots ont été supprimés à la demande de l'utilisateur. Les anciennes références
à ces fichiers dans les comptes rendus décrivent des résultats historiques ;
elles ne désignent plus des fichiers disponibles. Les synthèses, manifestes
revus, données applicatives et fixtures ont été conservés.
