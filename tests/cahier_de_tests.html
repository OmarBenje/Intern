Portée et lecture des statuts

Les statuts PASS reposent sur des réponses réellement observées. Les tests Django utilisent une base PostgreSQL créée et détruite par Django ; ils ne remplacent pas tous un parcours visuel. Les trois tests optionnels ignorés concernent un fournisseur de logos externe. Aucun envoi ATS, e-mail réel, stockage R2 ou déploiement sur trois machines virtuelles n'a été validé par ce cahier. Les commandes de reproduction figurent dans tests/README.md.
